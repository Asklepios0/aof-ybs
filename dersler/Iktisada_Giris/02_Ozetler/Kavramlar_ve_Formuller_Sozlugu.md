# 📚 İKTİSADA GİRİŞ (İKT101U) - Kavramlar, Tanımlar ve Formüller Sözlüğü (A - Z)

AÖF sınav sorularında doğrudan tanımı veya formülsel sonucu sorulan tüm terimler alfabetik sırayla derlenmiştir.

---

### 🔹 Basit Kredi Çarpanı
- **Açıklama / Formül:** Kredi Çarpanı = 1 / r (r: Zorunlu Karşılık Oranı).
- **Örnek / Sınav Uygulaması:** r = %20 ise çarpan = 1 / 0.20 = 5.

### 🔹 Basit Çarpan (Çoğaltan) Formülü
- **Açıklama / Formül:** k = 1 / (1 - MPC) = 1 / MPS.
- **Örnek / Sınav Uygulaması:** MPC = 0.75 ise k = 1 / (1 - 0.75) = 1 / 0.25 = 4.

### 🔹 Denk Bütçe Çarpanı
- **Açıklama / Formül:** Kamu harcamaları ve vergiler eşit miktarda artırıldığında çarpan k = 1'dir.

### 🔹 Doğal İşsizlik Oranı
- **Açıklama / Formül:** Doğal İşsizlik = Friksiyonel İşsizlik + Yapısal İşsizlik.

### 🔹 GSYH Deflatörü
- **Açıklama / Formül:** Deflatör = (Nominal GSYH / Reel GSYH) * 100.

### 🔹 Harcama Yoluyla GSYH
- **Açıklama / Formül:** GSYH = C + I + G + (X - M) (Tüketim + Yatırım + Kamu + Net İhracat).

### 🔹 İşsizlik Oranı Formülü
- **Açıklama / Formül:** İşsizlik Oranı = (İşsiz Sayısı / İşgücü) * 100.

### 🔹 Keynesyen MPC ve MPS Eşitliği
- **Açıklama / Formül:** MPC + MPS = 1. (MPC: Marjinal Tüketim Eğilimi, MPS: Marjinal Tasarruf Eğilimi).

### 🔹 M1 Para Arzı
- **Açıklama / Formül:** M1 = Dolaşımdaki Nakit + Vadesiz Mevduatlar.

### 🔹 M2 Para Arzı
- **Açıklama / Formül:** M2 = M1 + Vadeli Mevduatlar.

### 🔹 Marjinal Maliyet (MC)
- **Açıklama / Formül:** MC = ΔTC / ΔQ (Toplam maliyetin üretim miktarına göre türevi).

### 🔹 Talebin Fiyat Esnekliği Formülü
- **Açıklama / Formül:** ed = (%ΔQ) / (%ΔP) = [(Q2 - Q1) / Q1] / [(P2 - P1) / P1].

### 🔹 Talebin Gelir Esnekliği
- **Açıklama / Formül:** eI = (%ΔQ) / (%ΔI). Pozitif ise normal mal, negatif ise düşük mal.

### 🔹 Toplam Maliyet Eşitliği
- **Açıklama / Formül:** TC = TFC + TVC ve ATC = AFC + AVC.

### 🔹 Tüketici Dengesi Şartı
- **Açıklama / Formül:** MUx / Px = MUy / Py (Harcanan son liranın marjinal faydalarının eşitliği).

### 🔹 Vergi Çarpanı Formülü
- **Açıklama / Formül:** kt = -MPC / (1 - MPC).
- **Örnek / Sınav Uygulaması:** MPC = 0.80 ise kt = -0.80 / 0.20 = -4.

### 🔹 Çapraz Fiyat Esnekliği
- **Açıklama / Formül:** exy = (%ΔQx) / (%ΔPy). Pozitif ise ikame, negatif ise tamamlayıcı mal.
