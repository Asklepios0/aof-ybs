# 📚 İŞLETME İLKELERİ (İŞL101U) - Kavramlar, Tanımlar ve Formüller Sözlüğü (A - Z)

AÖF sınav sorularında doğrudan tanımı veya formülsel sonucu sorulan tüm terimler alfabetik sırayla derlenmiştir.

---

### 🔹 Carroll KSS Piramidi
- **Açıklama / Formül:** Ekonomik (Taban) -> Yasal -> Etik -> Filantropik/Gönüllü (Zirve).

### 🔹 Etkililik (Effectiveness)
- **Açıklama / Formül:** İşletmenin önceden belirlediği stratejik hedeflere ve amaçlara ulaşma derecesidir.

### 🔹 Greenwashing (Yeşil Yıkama)
- **Açıklama / Formül:** Çevre dostu olmayan ürünlerin aldatıcı reklamlarla çevreci gibi pazarlanması.

### 🔹 İktisadilik (Karlılık)
- **Açıklama / Formül:** İktisadilik = Satış Hasılatı / Katlanılan Toplam Maliyet.

### 🔹 Joint Venture (Ortak Girişim)
- **Açıklama / Formül:** İki şirketin belirli bir amaçla bir araya gelerek yeni bir tüzel kişilik oluşturması.

### 🔹 KOBİ Çalışan Sınırları
- **Açıklama / Formül:** Mikro: 1-9, Küçük: 10-49, Orta: 50-249 çalışan.

### 🔹 Maslow İhtiyaçlar Piramidi
- **Açıklama / Formül:** Fizyolojik -> Güvenlik -> Sosyal -> Saygınlık -> Kendini Gerçekleştirme.

### 🔹 Michael Porter Jenerik Stratejileri
- **Açıklama / Formül:** Maliyet Liderliği, Farklılaştırma, Odaklanma.

### 🔹 Pazarlamanın 4P'si
- **Açıklama / Formül:** Product (Ürün), Price (Fiyat), Place (Dağıtım), Promotion (Tutundurma).

### 🔹 PESTLE Analizi
- **Açıklama / Formül:** Politik, Ekonomik, Sosyo-kültürel, Teknolojik, Yasal, Ekolojik makro çevre faktörleri analizi.

### 🔹 Porter'ın 5 Güç Modeli
- **Açıklama / Formül:** Sektörel rekabet, potansiyel rakiplerin tehdidi, tedarikçilerin pazarlık gücü, alıcıların pazarlık gücü, ikame ürünlerin tehdidi.

### 🔹 Verimlilik Formülü
- **Açıklama / Formül:** Verimlilik = Üretilen Çıktı / Tüketilen Girdi.

### 🔹 Whistleblowing
- **Açıklama / Formül:** Kurum içindeki yasadışı veya etik dışı eylemlerin yetkililere ihbar edilmesi.

### 🔹 Yönetim Fonksiyonları (POLC)
- **Açıklama / Formül:** Planlama, Örgütleme, Yöneltme, Denetim.

### 🔹 Üretim Faktörleri ve Getirileri
- **Açıklama / Formül:** Emek -> Ücret, Sermaye -> Faiz, Doğal Kaynaklar -> Rant, Girişimci -> Kâr.
