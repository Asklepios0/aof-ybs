# 📚 MATEMATİK I (MAT105U) - Kavramlar, Tanımlar ve Formüller Sözlüğü (A - Z)

AÖF sınav sorularında doğrudan tanımı veya formülsel sonucu sorulan tüm terimler alfabetik sırayla derlenmiştir.

---

### 🔹 2x2 Matris Determinantı
- **Açıklama / Formül:** det |a b; c d| = a * d - b * c.
- **Örnek / Sınav Uygulaması:** det |3 2; 1 4| = 3*4 - 2*1 = 12 - 2 = 10.

### 🔹 2x2 Ters Matris Formülü
- **Açıklama / Formül:** A^-1 = (1 / det(A)) * [d -b; -c a].

### 🔹 Alt Küme Formülü
- **Açıklama / Formül:** n elemanlı bir kümenin alt küme sayısı = 2^n; özalt küme sayısı = 2^n - 1.
- **Örnek / Sınav Uygulaması:** s(A) = 5 ise alt küme sayısı = 2^5 = 32, özalt küme = 31.

### 🔹 Bölümün Türevi
- **Açıklama / Formül:** (f / g)' = (f' * g - f * g') / (g^2).

### 🔹 Cramer Kuralı
- **Açıklama / Formül:** xi = det(Ai) / det(A).

### 🔹 Dik Doğruların Eğimleri Bağıntısı
- **Açıklama / Formül:** m1 * m2 = -1 => m2 = -1 / m1.

### 🔹 Hessian Determinantı (Ekstremum)
- **Açıklama / Formül:** D = fxx * fyy - (fxy)^2. D > 0 ve fxx > 0 ise Min; D > 0 ve fxx < 0 ise Max; D < 0 ise Eyer noktası.

### 🔹 İki Noktadan Geçen Doğrunun Eğimi
- **Açıklama / Formül:** m = (y2 - y1) / (x2 - x1).
- **Örnek / Sınav Uygulaması:** A(1, 3) ve B(3, 7) noktaları için m = (7 - 3) / (3 - 1) = 4 / 2 = 2.

### 🔹 Kuvvet Türev Kuralı
- **Açıklama / Formül:** d(x^n)/dx = n * x^(n-1).
- **Örnek / Sınav Uygulaması:** d(4x^3)/dx = 12x^2.

### 🔹 Kâr Maksimizasyonu Şartı
- **Açıklama / Formül:** MR = MC (Marjinal Hasılat = Marjinal Maliyet).

### 🔹 Kümeler Birleşim Formülü
- **Açıklama / Formül:** s(A ∪ B) = s(A) + s(B) - s(A ∩ B).

### 🔹 L'Hopital Kuralı
- **Açıklama / Formül:** 0/0 veya ∞/∞ belirsizliklerinde lim [f(x) / g(x)] = lim [f'(x) / g'(x)].

### 🔹 Logaritma Çarpım ve Bölüm Kuralları
- **Açıklama / Formül:** log(x * y) = log(x) + log(y) ve log(x / y) = log(x) - log(y).

### 🔹 Marjinal Hasılat (MR)
- **Açıklama / Formül:** MR = d(TR) / dQ.

### 🔹 Marjinal Maliyet (MC)
- **Açıklama / Formül:** MC = d(TC) / dQ.

### 🔹 Parabol Kökler ve Diskriminant
- **Açıklama / Formül:** Δ = b^2 - 4ac. Kökler toplamı = -b / a, Kökler çarpımı = c / a.

### 🔹 Parabol Tepe Noktası Koordinatları
- **Açıklama / Formül:** f(x) = ax^2 + bx + c için r = -b / (2a) ve k = f(r) = (4ac - b^2) / (4a).
- **Örnek / Sınav Uygulaması:** f(x) = x^2 - 4x + 7 için r = -(-4)/(2*1) = 2. k = f(2) = 4 - 8 + 7 = 3. Tepe noktası T(2, 3).

### 🔹 Schwarz Teoremi
- **Açıklama / Formül:** fxy = fyx (Karma ikinci mertebe kısmi türevler eşittir).

### 🔹 Talebin Fiyat Esnekliği
- **Açıklama / Formül:** ε = (dQ/dP) * (P/Q).

### 🔹 Çarpımın Türevi
- **Açıklama / Formül:** (f * g)' = f' * g + f * g'.
