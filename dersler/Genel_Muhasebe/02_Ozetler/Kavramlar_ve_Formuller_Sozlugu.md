# 📚 GENEL MUHASEBE (MUH101U) - Kavramlar, Tanımlar ve Formüller Sözlüğü (A - Z)

AÖF sınav sorularında doğrudan tanımı veya formülsel sonucu sorulan tüm terimler alfabetik sırayla derlenmiştir.

---

### 🔹 690 Dönem Kârı veya Zararı
- **Açıklama / Formül:** Dönem sonunda tüm gelir ve gider hesaplarının devredildiği, kâr veya zararın net olarak toplandığı sonuç hesabıdır.

### 🔹 Alacak Senetleri Reeskontu
- **Açıklama / Formül:** Senetli alacakların dönem sonu itibarıyla peşin değerine indirgenmesi işlemidir. 657 Reeskont Faiz Giderleri Borç / 122 Alacak Senetleri Reeskontu Alacak kaydedilir.

### 🔹 Azalan Bakiyeler Amortismanı
- **Açıklama / Formül:** Amortisman Oranı = Normal Oran * 2 (Maksimum %50). Yıllık Amortisman = (Maliyet - Birikmiş Amortisman) * Oran.
- **Örnek / Sınav Uygulaması:** 100.000 TL makine, ömür 5 yıl -> Oran = (1/5)*2 = %40. 1. Yıl: 40.000 TL. 2. Yıl matrahı: 60.000 TL -> 24.000 TL amortisman.

### 🔹 Bilanço Eşitliği
- **Açıklama / Formül:** Varlıklar (Aktif) = Yabancı Kaynaklar (Kısa + Uzun Vadeli Borçlar) + Öz Kaynaklar.
- **Örnek / Sınav Uygulaması:** Varlıklar 500.000 TL, Borçlar 200.000 TL ise Öz Kaynaklar = 300.000 TL'dir.

### 🔹 Borç Senetleri Reeskontu
- **Açıklama / Formül:** Senetli borçların bilanço tarihindeki peşin değerine indirgenmesidir. 322 Borç Senetleri Reeskontu Borç / 647 Reeskont Faiz Gelirleri Alacak kaydedilir.

### 🔹 Brüt Satış Kârı (Zararı)
- **Açıklama / Formül:** Brüt Satış Kârı = Net Satışlar - Satılan Ticari Mallar Maliyeti (621 STMM).

### 🔹 Emisyon Primi (Hisse İhraç Primi)
- **Açıklama / Formül:** Hisse senetlerinin nominal bedelinden daha yüksek fiyatla ihraç edilmesi halinde aradaki pozitif fark (520 hesabı).

### 🔹 Faaliyet Kârı (Zararı)
- **Açıklama / Formül:** Faaliyet Kârı = Brüt Satış Kârı - (760 Pazarlama Giderleri + 770 Genel Yönetim Giderleri).

### 🔹 Kasa Sayım Fazlası
- **Açıklama / Formül:** Fiili sayım mevcudu > Defter mevcudu ise aradaki fark 397 Sayım ve Tesellüm Fazlaları hesabına alacak yazılır.

### 🔹 Kasa Sayım Noksanı
- **Açıklama / Formül:** Fiili sayım mevcudu < Defter mevcudu ise aradaki fark 197 Sayım ve Tesellüm Noksanları hesabına borç yazılır.

### 🔹 Kıst Amortisman (Binek Oto)
- **Açıklama / Formül:** İlk Yıl Amortismanı = (Yıllık Amortisman Tutarı / 12) * Kalan Ay Sayısı. Ayrılmayan kısım son yıla eklenir.

### 🔹 Net Satışlar Formülü
- **Açıklama / Formül:** Net Satışlar = Brüt Satışlar (600 Yurtiçi Satışlar) - Satış İndirimleri (610 Satıştan İadeler + 611 Satış İskontoları).

### 🔹 Normal Amortisman Formülü
- **Açıklama / Formül:** Yıllık Amortisman = Maliyet Bedeli / Faydalı Ömür = Maliyet Bedeli * (1 / n).
- **Örnek / Sınav Uygulaması:** 80.000 TL demirbaş, ömür 4 yıl -> Yıllık amortisman = 80.000 * %25 = 20.000 TL.

### 🔹 STMM Formülü (Aralıklı Envanter)
- **Açıklama / Formül:** STMM = Dönem Başı Emtia Mevcudu + Dönem İçi Net Alışlar - Dönem Sonu Emtia Mevcudu.
- **Örnek / Sınav Uygulaması:** Dönem başı mal: 50.000 TL, Alışlar: 150.000 TL, Dönem sonu sayım: 40.000 TL -> STMM = 50.000 + 150.000 - 40.000 = 160.000 TL.

### 🔹 Yasal Yedekler (I. Tertip)
- **Açıklama / Formül:** Türk Ticaret Kanunu uyarınca her yıl safi kârın %5'i, ödenmiş sermayenin %20'sine ulaşıncaya kadar yasal yedek olarak ayrılır.
